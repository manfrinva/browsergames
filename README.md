BrowserGames
Uma coleção de jogos que rodam diretamente no navegador.

O BrowserGames é um projeto dedicado à criação e disponibilização de jogos acessíveis pela web, sem necessidade de instalar programas ou utilizar plataformas específicas. A proposta é reunir experiências interativas em arquivos HTML, facilitando a execução, a experimentação e o compartilhamento.
Jogos disponíveis
Jogo	Descrição	Arquivo
Campo Zero: Greys	Jogo de suspense e sobrevivência com temática de invasão alienígena em ambiente rural.	[`Campo_Zero_Greys.html`](./Campo_Zero_Greys.html)


Novos jogos poderão ser adicionados ao repositório ao longo do desenvolvimento do projeto.
Como jogar
1. Acesse a lista de arquivos do repositório.
2. Escolha o jogo desejado e abra o arquivo HTML correspondente.
3. Clique em Download raw file para baixar o arquivo (ou clone o repositório).
4. Abra o arquivo .html em um navegador moderno, como Chrome, Firefox ou Edge.
Observação: a visualização do código HTML dentro do GitHub não executa o jogo. É necessário abrir o arquivo em um navegador. Alguns recursos podem depender das permissões do navegador.

Executar localmente com Git
git clone https://github.com/manfrinva/browsergames.git
cd browsergames
Depois, abra o arquivo HTML do jogo desejado no navegador.
Tecnologias
O projeto utiliza tecnologias web para disponibilizar os jogos diretamente no navegador:
- HTML: estrutura e ponto de entrada dos jogos.
- CSS: apresentação visual e interface, quando aplicável.
- JavaScript: lógica, interações e mecânicas de jogo, quando aplicável.
A implementação e os recursos específicos podem variar entre os jogos.
Objetivos do projeto
- Reunir jogos que possam ser executados diretamente no navegador.
- Facilitar o acesso e o compartilhamento de experiências interativas.
- Experimentar mecânicas, cenários e recursos de desenvolvimento web.
- Expandir gradualmente o catálogo com novos projetos.
